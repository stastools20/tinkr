How to install Tinkr

  1. Purchase a Tinkr token.
  2. You will receive an email containing a download link for the launcher.
  3. Download and run the Tinkr launcher (macOS or Windows).
  4. Enter your token inside the launcher. If the token is valid, the launcher will authenticate and unlock features.
  5. If World of Warcraft is detected, Tinkr will launch the game automatically.
